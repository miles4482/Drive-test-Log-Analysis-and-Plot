Focus points — where Robi CST gap comes from

1) Persistent gap (every idle pair): 183 return B→A + late QCI1 A-bearer — focus here first.
In all 18 close-RSRP idle pairs, Robi’s 183 takes ~0.6–0.75 s longer to reach UE-A than BL (median ~+0.66 s). Robi always starts QCI1 A-bearer late (after B’s 183, mean ~2.85 s); BL starts it early (mean ~0.19 s). This is the systematic IMS/PCRF timing issue.

2) Large outlier gap: INVITE → UE-B (IMS core / paging path).
When CST blows out (+4 s), it is almost all INVITE path (e.g. Robi pair 17179869212: INVITE→B ~5.24 s vs BL ~1.1–1.7 s, +3.5 to +4.1 s). Not radio: RSRP is matched. Focus IMS/core or paging delay before page/INVITE at UE-B.

Priority: (A) Fix late QCI1 + slow 183 return on every call — always present. (B) Investigate INVITE/paging path on outlier sessions (esp. 17179869212). PRACK/UPDATE (step 4) is not the main driver.
